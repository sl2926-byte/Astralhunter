# GALACTIC DEFENDER

#### A Retro-Futuristic Space Shooter

1\. Game Title

Galactic Defender

2\. Main Goal

Control a spaceship, survive waves of enemy spaceships, collect power-ups, and defeat the final boss to save the galaxy.

3\. Player Controls

- WASD or arrow keys: Move in four directions.
- Spacebar: Shoot lasers.

4\. Gameplay

The player fights different types of enemy spaceships. Some enemies chase the player, while others shoot bullets. The player must dodge attacks, destroy enemies, and survive increasingly difficult waves before facing the final boss.

5\. Scoring

- Scout Ship: 10 points.
- Fighter Ship: 20 points.
- Heavy Ship: 50 points.
- Power-up collection: 25 points.
- Survival bonuses: Extra points over time.

6\. Win/Lose Rules

- Start with 3 lives.
- Collisions and enemy bullets cost one life.
- Lose all 3 lives: Game Over.
- Defeat the final boss: Victory!

7\. First Version

The first version will feature:

- Player spaceship and movement.
- Three enemy spaceship types.
- Laser shooting and enemy attacks.
- Three lives and a scoring system.
- Three basic power-ups.
- Multiple enemy waves.
- One final boss with a health bar.
- Victory, Game Over, and Restart screens.

Technology and Publishing

- HTML for the game structure.
- CSS for the visual design.
- JavaScript for game mechanics.
- GitHub Pages for free online publishing.

The game will run directly in a web browser without a backend, database, paid service, login, or secret API key.
